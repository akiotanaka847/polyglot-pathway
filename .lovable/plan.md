

## Plan: Massive Lesson Quality Upgrade, Exam Realism, and Layout Fix

### Problems Identified

**1. Lessons are shallow and incomplete across all languages**

- **JP N5 and N4**: Hand-written with 25 lessons each but only 5-8 steps per lesson. Critically missing: Hiragana ka-row through wa-row, Katakana (entire system), basic Kanji (~80 kanji needed for N5), particles は/が/を/に/で/と in depth, verb groups explanation, adjective-i vs adjective-na conjugation, て-form rules for each verb group, existence verbs ある/いる, demonstratives この/その/あの, counters ~つ/~人/~本, etc.
- **FR A1 and A2**: Hand-written, 25 lessons each, ~5-7 steps per lesson. Missing deeper coverage of articles définis/indéfinis/partitifs, gender rules, verb groups (-er/-ir/-re) conjugation, negation patterns, être vs avoir distinction in passé composé, reflexive verbs, etc.
- **All other languages (15)**: Use `makeLessons` generator for A1 which produces very generic, skeletal lessons with only 2-5 steps each and no real teaching depth. Lessons like "Números 11-100" have only 2 steps with zero actual target-language content. Level 2-5 generators (`makeL2`, `makeL3`, `makeL4`, `makeL5`) have similar issues - they produce formulaic lessons with no authentic content.

**2. Exam simulators lack realism**

- Real JLPT has specific section structures: 言語知識 (Language Knowledge: Vocabulary, Grammar, Reading) with precise question formats (kanji reading, word usage in context, sentence completion, text comprehension with short/mid/long passages)
- Real DELF has 4 sections: Compréhension orale, Compréhension écrite, Production écrite, Production orale
- Current exams have 3 generic sections with 15 MC questions each, insufficient for realistic simulation
- Upper-level exams (B1-C2) generated by `makeB1/makeB2/makeC1/makeC2` are extremely generic - many languages share identical question structures with only vocab swapped, and some languages only have 8 questions per section

**3. Lesson UI requires excessive scrolling**

- The lesson page (`LessonPage.tsx`) has `py-6` padding on the content area and generous margins between elements
- Theory steps show large character blocks, notes, examples, and audio buttons stacked vertically
- On mobile this pushes the action button below the fold, requiring scrolling
- The sticky bottom bar is properly positioned, but the content area above could be more compact

### Changes

#### Phase 1: Layout/UI Fix (LessonPage.tsx)

- Reduce vertical padding from `py-6` to `py-3`
- Make theory card character display smaller (from `text-[2.5rem]` to `text-[2rem]` and reduce padding)
- Reduce margins between elements (`mb-3` to `mb-2`)
- Add `max-h-[calc(100dvh-52px-56px)]` to the content scroll area for better viewport fit
- Make the step indicator more compact
- Ensure question cards have tighter spacing on mobile

#### Phase 2: Expand JP Lessons to Certification Quality

**JP N5 (rewrite to ~25 lessons with 8-12 steps each):**

Expand existing lessons to include more steps with deeper content. Add missing critical topics:
- Katakana system (ア行 through ワ行) - at least 2 lessons
- Basic Kanji for N5 (~80 kanji) - 3 lessons covering most frequent ones
- Particle deep dives: は vs が, を, に vs で, と vs や, も, から/まで
- Verb conjugation by group: Group 1 (u-verbs) rules, Group 2 (ru-verbs) rules, irregular verbs
- Adjective conjugation: i-adjectives negative/past, na-adjectives with な/じゃない
- Demonstratives: この/その/あの and これ/それ/あれ
- Counters: ~つ, ~人, ~匹, ~本, ~個
- Existence: ある vs いる

Each existing lesson will get 3-5 additional steps (more theory, more varied exercises).

**JP N4 (expand steps in existing 25 lessons):**

Add 3-5 more steps per lesson to cover topics in more depth. Add exercises with reading passages and order exercises. Key additions:
- More て-form practice with all verb groups
- ている form for ongoing/resultative states
- ~ている vs ~てある
- More keigo examples and practice
- Causative-passive form
- ~ようになる
- More reading comprehension passages

**FR A1 and A2 (same expansion approach):**

Add 3-5 more steps per lesson. Key additions for A1:
- Article usage drills (le/la/les, un/une/des, du/de la/des)
- Verb group conjugation patterns with full tables
- Reflexive verbs introduction
- Negation with de vs des

For A2, expand:
- Passé composé agreement rules
- Imparfait vs passé composé usage drill
- Subjonctif forms for common verbs
- Pronoms en/y
- Plus-que-parfait and futur simple

#### Phase 3: Replace Generators with Richer Content

The `makeLessons`, `makeL2Lessons`, `makeL3`, `makeL4`, `makeL5` generators produce low-quality content. For the most studied languages, replace with hand-crafted content:

- **Chinese (HSK1-2)**: Tones system, pinyin, radicals, basic characters 你好/谢谢/对不起, measure words 个/只/本, sentence structures 是...的, 有/没有, 在, temporal markers 了/过/着
- **German (A1-A2)**: Cases (Nominativ/Akkusativ/Dativ/Genitiv), article declension, separable verbs, modal verbs, Perfekt with haben/sein, Präteritum
- **Korean (TOPIK1-2)**: Hangul jamo system, particles 은/는/이/가/을/를, honorific -요 system, verb conjugation, past tense -았/었, negative 안/못
- **Spanish (A1-A2)**: Ser vs estar, gender/number agreement, present tense conjugation (regular + stem-changing), reflexive verbs, preterite vs imperfect
- **Italian, Portuguese, etc.**: Expand A1 with more authentic vocabulary and grammar steps

For each language, increase step count per lesson from 2-5 to 6-10 steps minimum.

#### Phase 4: Exam Realism Upgrade

**JLPT exams:**
- Restructure sections to match real format: 文字・語彙 (Characters & Vocabulary), 文法 (Grammar with sentence completion), 読解 (Reading with short, mid, and long passages)
- Add more questions per section: N5=25 vocab + 20 grammar + 10 reading, N4=25+20+10, N3=25+25+15, N2=30+25+15, N1=30+30+15
- Include proper kanji reading questions (ふりがな format) and contextual word usage

**DELF exams:**
- Restructure to match DELF format: Compréhension des écrits (reading comprehension with multiple text types), Connaissance de la langue (grammar and vocabulary), Production écrite (writing prompts - simulated as MC about what you'd write)
- Add more authentic French reading passages

**Other certification exams:**
- HSK: Match official format with pinyin, characters, reading sections
- TOPIK: Match format with vocabulary, grammar, reading, listening description
- Goethe (German): Match A1-C2 format
- Add 25+ questions per section for all levels

**For generated exams (B1-C2):**
- Replace the generic generator with language-specific exam content
- Add reading comprehension passages with authentic-style texts for each language
- Ensure questions test genuine competency, not just vocabulary recognition

### Technical Details

- JP and FR lesson files will grow significantly (jp.ts from ~550 to ~1200+ lines, fr.ts from ~340 to ~800+ lines)
- Generator-based languages will get new hand-written data files or enhanced generators with much richer word banks and step templates
- Exam files will be expanded: `exams.ts`, `exams-advanced.ts`, `exams-a2.ts`, `exams-upper.ts` all get more questions and better structure
- LessonPage.tsx layout changes are CSS-only, no logic changes
- This is a very large change that will require multiple implementation passes

### Scope Management

Given the enormous scope, the implementation will prioritize:
1. **Layout fix** (immediate, small change)
2. **JP N5 + N4 deep expansion** (highest impact - Japanese is likely the most used language)
3. **FR A1 + A2 deep expansion** (second most popular)
4. **JLPT + DELF exam realism** (certification exams for the two main languages)
5. **Other language expansions** (Chinese, German, Korean, Spanish, then remaining)
6. **Upper-level exam improvements** (B1-C2 across all languages)
